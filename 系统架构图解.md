## 数据流图

### 1. 加载代码流程

```
PS (测试平台)                    FPGA (fpga_top_dynamic)
     │                                    │
     │  CMD_LOAD_CODE (0x10)              │
     ├──────────────────────────────────> │ STATE: IDLE → LOAD_LEN
     │                                    │
     │  长度 (16 bytes)                    │
     ├──────────────────────────────────> │ STATE: LOAD_LEN → LOAD_CODE
     │                                    │
     │  机器码字节 1                        │
     ├──────────────────────────────────> │ 存入 instr_buffer[7:0]
     │  机器码字节 2                        │
     ├──────────────────────────────────> │ 存入 instr_buffer[15:8]
     │  机器码字节 3                        │
     ├──────────────────────────────────> │ 存入 instr_buffer[23:16]
     │  机器码字节 4                        │
     ├──────────────────────────────────> │ 存入 instr_buffer[31:24]
     │                                    │ imem_we = 1
     │                                    │ 写入指令内存
     │                                    │
     │  ... (重复 4 次，共 4 条指令) ...      │
     │                                    │
     │  <────────────────────────────────┤ STATE: → SEND_DONE
     │            ACK (0x06)              │ 返回确认
     │                                    │ STATE: → IDLE
```

### 2. 执行代码流程

```
PS (测试平台)                    FPGA (fpga_top_dynamic)
     │                                    │
     │  CMD_RUN (0x20)                    │
     ├──────────────────────────────────> │ STATE: IDLE → RUN
     │                                    │ cpu_reset = 0
     │                                    │ cpu_run = 1
     │                                    │
     │                                    ▼
     │                          ┌──────────────────┐
     │                          │  CPU 开始执行     │
     │                          │                  │
     │                          │  PC=0x00: addi   │
     │                          │  x10 = 100       │
     │                          │                  │
     │                          │  PC=0x04: addi   │
     │                          │  x11 = 200       │
     │                          │                  │
     │                          │  PC=0x08: add    │
     │                          │  x12 = 300       │
     │                          │                  │
     │                          │  PC=0x0C: nop    │
     │                          │  done = 1        │
     │                          └──────────────────┘
     │                                    │
     │  <────────────────────────────────┤ cpu_done 检测到 nop
     │           DONE (0x0F)              │ STATE: → SEND_DONE
     │                                    │ STATE: → IDLE
```

### 3. 获取结果流程

```
PS (测试平台)                    FPGA (fpga_top_dynamic)
     │                                    │
     │  CMD_GET_RESULT (0x30)             │
     ├──────────────────────────────────> │ STATE: IDLE → GET_RESULT
     │                                    │ 读取 result_reg (x12)
     │                                    │
     │  <────────────────────────────────┤ 发送 result[7:0]
     │           0x2C                     │
     │  <────────────────────────────────┤ 发送 result[15:8]
     │           0x01                     │
     │  <────────────────────────────────┤ 发送 result[23:16]
     │           0x00                     │
     │  <────────────────────────────────┤ 发送 result[31:24]
     │           0x00                     │ STATE: → IDLE
     │                                    │
     │  组合成 32 位: 0x0000012C = 300     │
```

```
     │          │           ▼

     └───────────────────────┘
              │
              │ 接收 CMD_RUN

       ┌─────────────┐
       │     RUN     │ CPU 执行指令
       └──────┬──────┘

       ┌─────────────┐
```

```
             │         │         │         │         │

```

## UART 通信时序

```
波特率分频: BAUD_DIV = 10 (仿真加速，实际硬件 = 434)

发送 1 字节时序:
    
    ┌───┐   ┌───┐   ┌───┐   ┌───┐   ┌───┐   ┌───┐   ┌───┐   ┌───┐   ┌───┐   ┌───┐
    │   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │   │
────┘   └───┘ 0 └───┘ 1 └───┘ 2 └───┘ 3 └───┘ 4 └───┘ 5 └───┘ 6 └───┘ 7 └───┘   └────
    Start   D0    D1    D2    D3    D4    D5    D6    D7    Stop

    每位持续 BAUD_DIV 个时钟周期
    总共 10 位 = 10 * BAUD_DIV 时钟周期
```

## 关键信号说明

### 顶层信号
- `uart_rx`: UART 接收线 (FPGA 接收 PS 数据)
- `uart_tx`: UART 发送线 (FPGA 发送数据给 PS)
- `cpu_run`: CPU 运行使能
- `cpu_reset`: CPU 复位
- `cpu_done`: CPU 执行完成标志

### 内存接口
- `imem_we`: 指令内存写使能
- `imem_waddr`: 指令内存写地址 (0-63)
- `imem_wdata`: 指令内存写数据 (32 位)

### CPU 接口
- `PC`: 程序计数器
- `Instr`: 当前指令
- `result_x12`: x12 寄存器值（作为结果输出）

## 数据格式

### 小端序 (Little Endian)
所有多字节数据使用小端序传输：

```
32 位数据: 0x0000012C (300)
           ↓
传输顺序:  0x2C  0x01  0x00  0x00
           Byte0 Byte1 Byte2 Byte3
           (LSB)             (MSB)
```

### 机器码格式
RISC-V 32 位指令：

```
addi x10, x0, 100  =  0x06400513

二进制拆解:
  0000 0110 0100 0000 0000 0101 0001 0011
  |         |         |         |         |
  imm[11:0] rs1[4:0]  funct3    rd[4:0]   opcode
  000001100100 00000   000      01010     0010011
  
  100(10进制) 00000(x0) ADD     01010(x10) I-type
```

## 调试技巧

1. **查看状态机**: `[STATE]` 标记显示状态转换
2. **查看内存写入**: `[IMEM_WR]` 标记显示指令加载
3. **查看 CPU 执行**: `[CPU]` 标记显示寄存器变化
4. **查看 UART 通信**: `[TX]` 和 `[RX]` 标记显示数据传输
5. **使用波形**: 打开 `.vcd` 文件查看信号时序
